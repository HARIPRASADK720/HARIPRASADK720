**Architecture**

```text
Next.js / TypeScript
        │
        ▼
Spring Boot REST API
        │
 ┌──────┼────────┐
 ▼      ▼        ▼
RAG   Security  Domain Services
 │      │        │
 ▼      ▼        ▼
AI    JWT     PostgreSQL
               │
              Redis
```

### Engineering Highlights

* 🔎 Grounded **RAG semantic retrieval**
* 🧠 Controlled AI conversation architecture
* 🔐 JWT authentication + role-based authorization
* 🛡️ BOLA / IDOR protection

* 🧪 Unit and integration testing

**Core Stack**

`Docker` `GitHub Actions` `JUnit 5`

```text
ASSESS

UNDERSTAND
   ↓
ADAPT
   ↓
EXPLAIN
   ↓
RECOMMEND
   ↓
REASSESS
```

Instead of being a simple quiz application, the system combines **RAG, controlled agent workflows, adaptive difficulty, AI tutoring and technical interview evaluation**.
